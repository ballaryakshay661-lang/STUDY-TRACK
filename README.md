# STUDY-TRACK

📚 StudyTrack — Student Assignment & Deadline Tracker

A simple and responsive web application that helps students organize assignments, manage deadlines, and track their academic progress.

🎯 About the Project

StudyTrack helps students manage their academic tasks in one place. It provides a dashboard to add assignments, set due dates, prioritize work, and track completion.

❗ Problem Statement

Students often forget deadlines and struggle to organize multiple assignments. StudyTrack provides a centralized solution for managing assignments and monitoring pending work.

✨ Features

- Add assignments with a name, subject, due date, and priority.
- View all assignments in a dashboard.
- Mark assignments as completed or pending.
- Edit and delete assignments.
- Filter assignments by status.
- Track pending, completed, and overdue tasks.
- Save assignments using browser localStorage.
- Responsive interface for desktop and mobile devices.

🚀 Getting Started

Prerequisites

- Visual Studio Code
- A modern web browser
- Live Server extension (recommended)

Installation

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Open "index.html".

4. Right-click and select Open with Live Server.

📖 How to Use

1. Enter an assignment name and subject.
2. Choose a due date and priority.
3. Add the assignment.
4. View and filter your assignments.
5. Mark tasks as completed when finished.
6. Edit or delete tasks when needed.

💾 Data Storage

StudyTrack uses browser localStorage to save assignments locally. Data is not automatically synchronized across devices, and clearing browser storage may remove saved tasks.
